# Night Sort

Night Sort is a portrait-first Android sorting roguelite built with Godot.

You run a tiny night logistics hub. Parcels keep moving, and you tap junctions to route each parcel to the matching color + shape gate. The controls stay simple while traffic, modifiers and run upgrades create the pressure.

## Current state
Version **0.1.0-alpha** is playable and has a verified Android APK build.

What is already in:
- normal 90-second shifts;
- deterministic Daily Shift;
- score, combo, mistakes and records;
- mid-run upgrade choices;
- credits and unlockable upgrade licenses;
- weekly contracts;
- persistent local save;
- procedural sound/haptics;
- automated tests and Android builds.

Latest verified Android build:
https://github.com/linkovme/night-sort/actions/runs/34944190874

Open the run and download the artifact named **night-sort-debug-apk**.
