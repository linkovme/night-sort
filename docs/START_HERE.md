# START HERE — Night Sort

Этот файл — первая точка входа для любого нового чата или разработчика.

## Что мы делаем
Night Sort — вертикальная Android-игра на Godot 4.7.2. Игрок управляет развилками маленького ночного сортировочного центра и направляет посылки в правильные выходы. Управление — одним пальцем, глубина — из нарастающего потока, комбинаций механик и выбора улучшений.

## Источник истины
Чат НЕ является источником истины. Истина хранится в этом репозитории.

Перед любой работой прочитай:
1. `docs/PROJECT_STATE.md` — текущее состояние и следующая задача.
2. `docs/GAME_DESIGN.md` — правила игры.
3. `docs/DECISIONS.md` — уже принятые решения, которые нельзя молча переигрывать.
4. Нужные по задаче документы из `docs/`.

## Технология
- Godot 4.7.2 stable
- GDScript
- Portrait-first: 1080×1920, stretch под разные экраны
- Первая платформа: Android
- GitHub Actions проверяет проект

## Правила работы
- После значимого изменения обновлять `PROJECT_STATE.md`.
- Изменение фундаментального решения записывать в `DECISIONS.md`.
- Не хранить секреты, ключи подписи и рекламные ключи в Git.
- Делать маленькие законченные шаги: каждый основной коммит должен оставлять проект запускаемым.
- Не добавлять случайные ассеты разных стилей. Визуальная система описана в `ART_BIBLE.md`.
